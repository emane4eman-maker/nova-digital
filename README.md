# NOVA DIGITAL

### Creative Digital Agency Website

NOVA DIGITAL is a modern, responsive digital agency website designed to showcase digital services, creative projects, and contact information in a professional and user-friendly layout.

## Project Overview

This project was developed as a Front-End Development training project. It demonstrates the use of modern web technologies to create a responsive website for a digital agency.

## Features

- Responsive design for desktop, tablet, and mobile devices.
- Navigation bar with links to the main sections.
- Hero section introducing the digital agency.
- About Us section presenting the agency's mission and vision.
- Services section showcasing digital services.
- Portfolio section displaying sample projects.
- Contact form with client-side validation.
- Smooth navigation and back-to-top button.
- Dynamic footer year.
- Modern dark theme with purple and cyan accents.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Google Fonts
- Unsplash images

## How to Run the Project

1. Download or clone the project folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. View the website in your browser.

An internet connection is required to load the external Bootstrap resources, Google Fonts, and remote portfolio images.

## Contact Form

The contact form currently provides client-side validation only. It does not send messages to a server or email address.
